DESIGNATION OF OPEN GAME CONTENT
--------------------------------

The following files are Open Game Content. They contain game rule
information -- codes, tables, and their meanings -- derived from the
Cepheus Engine System Reference Document:

  packages/core/src/ruleset/cepheus1/size.ts
  packages/core/src/ruleset/cepheus1/atmosphere.ts
  packages/core/src/ruleset/cepheus1/hydrographics.ts
  packages/core/src/ruleset/cepheus1/prose.ts

Within those files, the Open Game Content is the rules-derived data: the
code-to-value mappings and the plain-English meanings of each code. The
surrounding TypeScript -- type declarations, module structure, and the
explanatory comments about this project's design decisions -- is not.

Two columns in those tables are NOT derived from any ruleset and are not
Open Game Content: `craterPreservation` and `baseTemperature` in the
atmosphere table, and `terrainAmplitudeM`, `fbmFrequency` and `fbmOctaves`
in the size table. They are this project's own invention and each file
says so where it defines them.
